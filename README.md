# python-project3

《挑战课题—Python 编程》课题 3：**神经网络编程 —— 基于 PyTorch 的 MNIST 手写数字识别**。

本仓库当前收录课题 3 的**原理精读文档**，讲清任务要求、神经网络原理、CNN、MNIST 训练流程与报告写法。

## 打开文档

下载仓库后，用浏览器打开：

```
docs/课题3-神经网络-原理精读.html
```

单文件页面，不依赖网络；右上角可切换亮暗主题，也可复制 Markdown 源稿。

## 内容

| 章节 | 讲什么 |
| ---- | ------ |
| A 课题要交什么 | 三条任务、报告 a/b/c、环境准备 |
| B 神经元与激活函数 | 加权和、偏置、Sigmoid / Tanh / ReLU / Softmax |
| C 网络拓扑与前向传播 | 784 → 512 → 10、矩阵形式、参数量 |
